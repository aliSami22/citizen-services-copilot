منصة Agentic RAG لخدمات المواطنين الحكومية

D4 + T3

منصة ذكاء اصطناعي تساعد المواطن على معرفة حقوقه والإجراءات المطلوبة. النظام يستوعب المستندات الرسمية، يجيب على الأسئلة بإجابات مستندة على المصادر فقط — ويرفض الإجابة عندما لا يجد مصدرًا موثوقًا. للمواضيع المعقدة، يشغّل ثلاثة وكلاء AI متخصصين، ثم يتطلب موافقة موظف حكومي قبل إرسال أي رد.

1. استيعاب المستندات

تقسيم النص إلى chunks، توليد embedding بأبعاد 768، وتخزينها في pgvector.

2. بحث هجين

دمج البحث الدلالي والبحث بالكلمات المفتاحية عبر RRF.

3. إجابات مستندة

كل جملة مربوطة بمصدرها. رفض صريح عند غياب الدليل.

4. ثلاثة وكلاء

Eligibility، Procedure، Drafter مع orchestrator.

5. بوابة الموافقة

موظف يراجع قبل الإرسال. القرارات مسجّلة.

6. الحاكم المالي T3

ميزانية لكل مستخدم، تحقق مسبق، قطع فوري.

.NET 10 · Clean Architecture · PostgreSQL + pgvector · Multi-Agent · JWT · SSE · OWASP LLM Top 10

تسجيل الدخول

سجّل دخولك كمواطن للاستفسار أو كموظف لمراجعة القرارات والموافقة عليها.

استيعاب مستند رسمي

استيعاب المستندات، تجزئتها، توليد التمثيلات المتجهية، وتخزينها في pgvector.

اسأل سؤالاً (Agentic RAG)

إجابة مستندة فقط على المصادر المعتمدة — رفض فوري عند غياب الدليل الموثوق.

تشغيل سير العمل متعدد الوكلاء (Workflow)

تشغيل الوكلاء الثلاثة (الأهلية، الإجراءات، الصياغة) تحت إشراف المنسق وبوابة الموافقة البشرية.

الميزانية ومراقبة الاستهلاك (T3)

الحاكم المالي T3: تحقق مسبق من الميزانية، وتتبع التوكنز، وقطع فوري عند الاستنفاذ.

سجلات القرارات المعمارية (ADRs)

  • ADR-001: pgvector للتخزين والبحث الدلالي فائق السرعة.
  • ADR-002: Chunking بالنصوص المتراكبة لضمان اكتمال السياق.
  • ADR-003: بحث هجين عبر RRF (Reciprocal Rank Fusion) لدمج الدلالي والنصي.
  • ADR-004: تجريد مزود الـ LLM لدعم النماذج المحلية والسحابية بسلاسة.
  • ADR-005: Orchestration بـ State Machine لإدارة تعاقب الوكلاء المتخصصين.
  • ADR-006: الحاكم المالي T3 لحظر تجاوز الميزانية وحماية الموارد.
